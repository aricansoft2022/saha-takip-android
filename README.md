# Saha Takip Android

Offline-first Android saha takip uygulaması.

Bu depo, şantiye imalat ilerlemesi, problem kodları, tarihçeli notlar, bağlama bağlı fotoğraflar ve rapor üretimi için native Android uygulamasını içerir.

## Durum

v0 geliştirmesi `v0-foundation` dalında yürütülür.

## Temel ilkeler

- Saha kullanımı masaüstü Excel kopyası değildir.
- Veri girişi blok/imalat bağlamında mümkün olduğunca tek elle yapılır.
- Fotoğraf çekildiği ekranın proje/blok/imalat bağlamını otomatik devralır.
- İlerleme, kalite, kontrol ve bloke durumu ayrı eksenlerdir.
- Problem tanımları tekrar kullanılabilen bir katalogdur; saha problem kayıtları ayrı yaşam döngüsüne sahiptir.
- Not ve fotoğraflar tarihçelidir ve ayrı ayrı rapora dahil/hariç bırakılabilir.
- Uygulama internet olmadan çalışır.
